# SupplyForge

A decentralized supply chain transparency platform built on Stacks blockchain that enables end-to-end product tracking from manufacturer to consumer.

## Features

- **Manufacturer Registration**: Register with certifications and build trust scores
- **Product Batch Creation**: Create trackable product batches with quality ratings
- **Supply Chain Tracking**: Track products through the entire supply chain
- **Trust Score System**: Build reputation through verified transactions
- **Category Management**: Organize products by categories with proper certifications

## Smart Contract Functions

### Admin Functions
- `set-contract-owner`: Transfer contract ownership
- `set-platform-fee`: Adjust platform fee percentage
- `add-product-category`: Add new product categories

### Manufacturer Functions
- `register-manufacturer`: Register as a certified manufacturer
- `update-certifications`: Update manufacturer certifications
- `create-batch`: Create new product batches for tracking

### Tracking Functions
- `track-batch`: Track a product batch through the supply chain
- `claim-trust-score`: Claim earned trust score rewards

## Getting Started

1. Deploy the contract to Stacks blockchain
2. Register as a manufacturer with relevant certifications
3. Create product batches with quality ratings
4. Track batches through the supply chain
5. Build trust score through verified transactions
